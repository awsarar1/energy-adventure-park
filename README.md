# مدينة ملاهي الطاقة • Energy Adventure Park

**عمل الطالبة سرى أوس أبوعيد**

محاكاة عربية لدرس الشغل والطاقة (2-1) ودرس حفظ بقاء الطاقة (3-1)، للصف الثاني عشر العلمي في الكويت، الفصل الأول 2026–2027.

## تشغيل النسخة الجاهزة للعرض

1. فكّي ضغط ملف المشروع في مجلد. تأكدي من وجود **Node.js 22.18 أو أحدث**.
2. افتحي الطرفية في المجلد وشغّلي `npm start`. على Windows، استخدمي `npm.cmd start` إذا منع PowerShell تشغيل `npm`.
3. افتحي [النسخة المحلية](http://127.0.0.1:4173/) في Chrome أو Edge مع تفعيل تسريع الرسومات. استعملي Ctrl+C لإغلاق الخادم.

يتضمن الأرشيف مجلد `dist` الجاهز. يعمل هذا المسار دون اتصال بالإنترنت أو تثبيت اعتماديات، ويستخدم Node.js لتقديم الملفات من الجهاز نفسه.

## تطوير المشروع واختباره

```sh
npm ci
npm run dev
npm test
npm run build
```

استخدمي عنوان Vite الذي يظهر في الطرفية أثناء التطوير. يستلزم تثبيت الاعتماديات أول مرة اتصالًا بالإنترنت. يستخدم المشروع React وTypeScript وVite وThree.js، وخط Noto Sans Arabic المضمّن محليًا.

- `src/physics.ts` يحسب الحركة والطاقة على طول السكة.
- `src/Park.tsx` يبني المشهد ثلاثي الأبعاد ويعرض موضع كل عربة.
- `src/EnergyChart.tsx` يعرض عينات محرك الفيزياء ويتيح فحصها بالنقر أو بلوحة المفاتيح.
- `src/main.tsx` يربط التحكم والتجارب والتحديات ووضع العرض.
- `test/physics.test.ts` يتحقق من حفظ الطاقة والسرعة عند B وتغيّر الكتلة والارتفاع والاحتكاك والارتداد والاستئناف.

## استخدام المحاكاة

- اختاري «ابدئي التجربة» للانتقال إلى لوحة التحكم. عند تعديل الكتلة أو الارتفاع أو الاحتكاك تعود العربة إلى A وتبدأ تجربة جديدة بشروطك.
- ابدئي الحركة أو أوقفيها مؤقتًا. سرعة العرض تغيّر معدل مرور زمن المحاكاة، وتبقى القوانين نفسها. زر إعادة التجربة يعيد العربة إلى السكون عند A.
- اسحبي داخل المشهد لتغيير زاوية الكاميرا. استخدمي أزرار التكبير والتصغير وإعادة الزاوية. اضغطي Escape للخروج من المشهد الموسّع.
- في وضع المقارنة، تتحرك العربة الوردية دون احتكاك والسماوية مع الاحتكاك. تعرض لوحة القياسات الوردية أولًا. تستخدم السماوية قيم الصف الثاني في بطاقات الطاقة وخطوطًا متقطعة في الرسم.
- لتقديم الدرس، افتحي «وضع العرض المدرسي» وانتقلي يدويًا بين المراحل الست. تحتوي على نص قصير للشرح وتجربتين وتحدٍّ.
- للتحقق من المثال الدراسي، اضبطي الكتلة على 500 kg والارتفاع على 20 m واختاري «بدون احتكاك». تبلغ الطاقة الميكانيكية 100,000 J والسرعة عند B تساوي 20 m/s.

## نموذج الحركة

يبدأ القطار من السكون، وارتفاع القاع B يساوي صفرًا، وارتفاع C نصف ارتفاع A. تُنمذج السكة كمقاطع قصيرة معلومة الطول والميل. يحل المحرك الحركة بتسارع ثابت داخل كل مقطع ويفصل الخطوة الزمنية عند عبور الوصلات أو عند وصول السرعة إلى الصفر. تحسب السرعة مجددًا من ميزانية الطاقة لتقليل الخطأ العددي المتراكم.

نستخدم `g = 10 m/s²` ونمثّل العربة بنقطة على السكة. نستخدم نموذج احتكاك تعليميًا بقوة ثابتة المقدار `f = μmg`، ونستخدم القيمة نفسها حدًا مبسطًا لبدء الحركة من السكون. يراكم المحرك `ΔU` حسب المسافة المقطوعة على السكة حتى أثناء الارتداد. تبقى `ME + ΔU` ثابتة ضمن خطأ التقريب الحسابي. ينتهي القياس عند وصول العربة إلى C أو عند استقرارها. الأرقام المرئية مقربة للعرض، بينما الحسابات تستخدم القيم كاملة.

المجسمات مبنية برمجيًا وتعمل محليًا. يحتاج عرضها إلى WebGL 2.
